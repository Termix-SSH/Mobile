Termix 2.1.0 adds actions on a host: every action the server's plugins offer, like restarting a container or service, with a form, a dry run and the result. Approvals and Run history are under Tools when the server has Operations Center. WireGuard, Privileged Access, Ansible, DNS, Git, Network Devices, Notes, Object Storage, Out-of-band, Storage Health, UPS Manager and Virtual Machines now open in the app.
